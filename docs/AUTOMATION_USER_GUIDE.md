# HMCL 自动化功能使用指南

## 📖 功能概览

HMCL 新增的自动化功能可以帮助您更方便地管理游戏启动，主要包括：

### 🎯 三大核心功能

1. **服务器书签** - 保存常用服务器，一键连接
2. **快速启动** - 预设启动参数组合，一键启动
3. **快捷方式** - 创建桌面快捷方式，快速启动

---

## 🚀 快速开始

### 1️⃣ 服务器书签管理

#### 添加书签

1. 打开 HMCL 主界面
2. 进入"自动化工具"标签页
3. 点击"服务器书签"
4. 点击右上角的 "+" 按钮
5. 填写信息：
   - **名称**: 给书签起个名字，如"生存服"
   - **服务器地址**: 如 `play.example.com:25565`
   - **关联版本**: (可选) 选择这个服务器推荐的游戏版本
6. 点击"确定"

#### 连接服务器

1. 在书签列表中找到要连接的服务器
2. 点击"连接"按钮
3. HMCL 将自动启动游戏并连接到服务器

#### 编辑/删除书签

- **编辑**: 选中书签，点击"编辑"按钮
- **删除**: 选中书签，点击"删除"按钮

💡 **提示**: HMCL 会自动记录您最近使用的服务器，方便快速访问！

---

### 2️⃣ 快速启动配置

#### 创建快速启动

1. 进入"自动化工具"标签页
2. 点击"快速启动"
3. 点击"+"按钮
4. 填写配置信息：
   - **名称**: 如"我的生存世界"
   - **游戏版本**: 选择要启动的版本，如 `1.20.1`
   - **服务器地址**: (可选) 输入服务器地址，如 `survival.example.com:25565`
5. 点击"确定"

#### 使用快速启动

1. 在快速启动列表中找到配置
2. 点击"启动"按钮
3. HMCL 将使用预设的参数启动游戏

💡 **高级选项** (可在配置中设置):
- 最大内存分配
- 是否全屏启动
- 使用特定 Java 版本
- 指定游戏账户

---

### 3️⃣ 创建快捷方式

#### 创建桌面快捷方式

1. 进入"自动化工具"标签页
2. 点击"创建快捷方式"
3. 填写信息：
   - **快捷方式名称**: 如"My Server"
   - **游戏版本**: 选择版本
   - **服务器地址**: (可选) 输入服务器地址
   - **快捷方式类型**: 
     - 桌面快捷方式
     - 开始菜单快捷方式
   - **创建启动脚本**: 勾选可同时创建启动脚本文件
4. 点击"确定"

#### 支持的平台

| 操作系统 | 快捷方式类型 | 生成的文件 |
|---------|------------|-----------|
| Windows | 桌面/开始菜单 | `.bat` 批处理文件 |
| macOS | 桌面 | `.command` 脚本文件 |
| Linux | 桌面 | `.desktop` 文件 |

💡 **提示**: 快捷方式会自动保存游戏版本和服务器信息！

## 🎮 实际使用场景

### 场景 1: 管理多个服务器

**问题**: 您玩多个服务器，手动输入地址很麻烦

**解决方案**: 
1. 为每个服务器创建书签
2. 一键快速连接
3. 系统自动记录使用频率

**操作步骤**:
```
书签1: 生存服 | play.survival.com:25565
书签2: 空岛服 | skyblock.example.com:25565
书签3: 小游戏 | minigames.example.com:25565
```

### 场景 2: 快速启动常用配置

**问题**: 每次启动游戏都要调整设置

**解决方案**:
1. 创建快速启动配置，包含：
   - 游戏版本
   - 服务器地址
   - 内存分配
   - 账户选择
2. 一键启动

**示例配置**:
```
配置名: 生存服启动
版本: 1.20.1
服务器: survival.example.com:25565
内存: 4GB
全屏: 否
```

### 场景 3: 创建桌面快捷方式

**问题**: 想从桌面快速启动特定服务器

**解决方案**:
1. 创建桌面快捷方式
2. 双击即可启动游戏并连接服务器

**效果**:
```
桌面上的快捷方式:
📁 我的生存服.lnk
   ↓
   └─> 启动 HMCL → 选择版本 1.20.1 → 连接 survival.example.com:25565
```

## 💡 高级技巧

### 1. 使用启动脚本

创建快捷方式时勾选"同时创建启动脚本"，会在用户目录下生成脚本文件。

**脚本位置**:
- Windows: `C:\Users\用户名\HMCL Scripts\`
- macOS: `/Users/用户名/HMCL Scripts/`
- Linux: `/home/用户名/HMCL Scripts/`

**使用方法**:
```bash
# macOS/Linux
cd ~/HMCL\ Scripts
./我的服务器.command

# Windows
cd %USERPROFILE%\HMCL Scripts
我的服务器.bat
```

### 2. 版本关联

在书签中关联游戏版本后，可以：
- 自动使用匹配的版本启动
- 版本不匹配时提示更新
- 快速切换不同版本的服务器

### 3. 使用统计

HMCL 自动统计：
- 📊 每个书签的使用次数
- ⏰ 最近使用的书签排在前面
- 🔥 最常用的书签

这帮助您快速找到常用的服务器！

## 🔧 故障排除

### 快捷方式无法创建

**可能原因**:
1. 权限不足
   - **解决**: 以管理员身份运行 HMCL
2. 目录不存在
   - **解决**: 确保桌面目录存在
3. 路径包含非法字符
   - **解决**: 避免使用 `\/:*?"<>|` 字符

**解决方案**:
```bash
# Windows - 检查权限
icacls %USERPROFILE%\Desktop

# macOS - 检查权限
ls -la ~/Desktop

# Linux - 检查权限
ls -la ~/桌面
```

### 服务器地址无效

**可能原因**:
1. 地址格式错误
   - **正确格式**: `example.com:25565` 或 `192.168.1.1:25565`
   - **IPv6格式**: `[::1]:25565`
2. 端口号错误
   - **范围**: 1-65535

**验证方法**:
在浏览器中测试地址是否可以解析

### 数据丢失

**预防措施**:
1. 定期备份配置文件
2. 配置文件位置：
   - `~/.hmcl/server_bookmarks.json`
   - `~/.hmcl/quick_launch.json`

**恢复方法**:
1. 找到备份文件
2. 复制到正确位置
3. 重启 HMCL

## 🎯 最佳实践

### ✅ 推荐做法

1. **为书签命名清晰**
   - ❌ 不好: `server1`
   - ✅ 好: `生存服-主城`

2. **关联合适的版本**
   - 每个服务器可能有推荐版本
   - 使用关联版本避免兼容性问题

3. **定期备份**
   - 备份 JSON 配置文件
   - 防止数据丢失

4. **整理快捷方式**
   - 创建有意义的名称
   - 分类管理不同类型的快捷方式

### ❌ 避免事项

1. **不要使用特殊字符**
   - 快捷方式名称避免: `\/:*?"<>|`

2. **不要创建过多书签**
   - 保持列表简洁
   - 优先使用最常用的

3. **不要忽视权限问题**
   - 确保 HMCL 有创建文件的权限
   - 必要时使用管理员权限
